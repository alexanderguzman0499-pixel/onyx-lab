# Onyx Lab

Sitio estático (HTML/CSS/JS) para Onyx Lab, catálogo B2B de péptidos y compuestos de grado investigación. Venta restringida a laboratorios e instituciones verificadas — Research Use Only, no apto para consumo humano ni veterinario.

## Estructura

- `index.html` — página principal: hero, catálogo, proceso de verificación, cumplimiento, formulario de contacto.
- `compliance.html` — política de cumplimiento y uso de investigación.
- `thanks.html` — página de confirmación tras enviar el formulario.
- `styles.css` — estilos (tema oscuro).
- `app.js` — JS mínimo.
- `netlify.toml` — configuración de despliegue en Netlify (el formulario de contacto usa Netlify Forms).

## Pendiente antes de publicar

- Reemplazar el dominio de ejemplo (`onyxlab.example.com`) en `index.html`, `compliance.html` y `robots.txt` por el dominio real.
- Cargar COAs reales y confirmar CAS/pureza de cada compuesto con el proveedor real antes de publicar precios o fichas técnicas definitivas.
- Revisar la Política de Cumplimiento con asesoría legal antes de operar (venta de research chemicals está sujeta a regulación).
